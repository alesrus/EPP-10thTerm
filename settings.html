Editor access (GitHub key)

Saving the mission for everyone needs a GitHub access token on this device. It stays only in this browser. Colleagues without a token can look at the settings but not change them.

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  2. Repository access: Only select repositories → EPP-10thTerm.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate it, copy it and paste it above.
